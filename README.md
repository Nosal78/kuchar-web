# kuchar-web

Statické stránky aplikace Kuchař na GitHub Pages (`https://nosal78.github.io/kuchar-web/`).
Repozitář je veřejný, protože GitHub Pages je na bezplatném účtu jen pro veřejné repozitáře –
proto tu nejsou žádná data ani klíče.

- `pozvanka/?kod=ABCD2345` – otevře aplikaci odkazem `kuchar://pozvanka/ABCD2345`
  (s `&app=dev` vývojovou variantu `kuchar-dev://`), jinak ukáže kód k opsání.
- `soukromi/` – zásady ochrany soukromí (odkaz pro Google přihlášení a Google Play).
- `ucet-smazat/` – jak smazat účet a údaje, i bez aplikace (požadavek Google Play, Fáze 11).

Zdrojový kód aplikace je v soukromém repozitáři `Nosal78/kuchar-app` (viz `docs/DISTRIBUCE.md` §9a).
